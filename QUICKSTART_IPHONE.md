# 🚀 INSTALAR NO IPHONE AGORA - GUIA RÁPIDO

## ⚡ 2 MINUTOS PARA TER O APP NO IPHONE!

### **MÉTODO SUPER RÁPIDO (Servidor Local)**

Você pode testar **AGORA MESMO** sem hospedar online!

---

## 📋 PASSO A PASSO

### **1️⃣ No Seu Computador (Windows)**

```cmd
1. Abra o Prompt de Comando (cmd)
2. Navegue até a pasta pwa/
3. Digite: python -m http.server 8080
4. Pressione Enter
5. Anote o IP que aparecer (exemplo: Serving HTTP on :: port 8080)
```

**Para descobrir seu IP:**
```cmd
ipconfig
```
Procure por "IPv4" - geralmente algo como `192.168.1.5`

---

### **2️⃣ No Seu iPhone**

```
1. Conecte na MESMA rede Wi-Fi do computador
2. Abra o Safari (importante: use Safari!)
3. Digite na barra: http://SEU-IP:8080
   Exemplo: http://192.168.1.5:8080
4. Pressione Enter
5. Aguarde o app carregar (tela roxa)
```

---

### **3️⃣ Adicionar à Tela Inicial**

```
1. Toque no botão Compartilhar ⎋ 
   (ícone de caixa com seta no Safari)
2. Role para baixo
3. Toque em "Adicionar à Tela de Início" ➕
4. Toque em "Adicionar"
```

---

### **4️⃣ PRONTO! 🎉**

```
1. Vá para a tela inicial do iPhone
2. Encontre o ícone "LinguaAI"
3. Toque para abrir
4. Use como app nativo!
```

## ❓ PROBLEMAS COMUNS

### "Não encontra o IP"
- ✅ iPhone e PC na MESMA rede Wi-Fi
- ✅ IP correto (use `ipconfig` no Windows)
- ✅ Porta 8080 incluída

### "Safari não carrega"
- ✅ Servidor rodando no PC?
- ✅ Firewall bloqueando? Desative temporariamente

### "Não aparece opção de adicionar"
- ✅ Use Safari (não Chrome!)
- ✅ Toque em Compartilhar primeiro
